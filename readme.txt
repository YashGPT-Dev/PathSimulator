PathVision is an interactive pathfinding visualizer built with React and Vite.

Features:
• Interactive grid system
• Wall creation using mouse drag
• BFS pathfinding visualization
• Animated visited nodes and shortest path
• Start and finish node indicators
• Clear board functionality

Upcoming:
• DFS Visualization
• Dijkstra Algorithm
• A* Search
• Maze Generation
• Drag-and-drop start/finish nodes
